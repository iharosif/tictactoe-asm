# TicTacToe - ASM

TicTacToe játék megvalósítása x86_64 assemblyben libc nélkül.

Csak Linux-alapú operációs rendszeren működik.

A makefile futtatása előtt létre kell hozni egy **build/** könyvtárat

A projekt futtatása egy sorban:
```bash
git clone https://github.com/iharosif/tictactoe-asm.git && cd tictactoe-asm && mkdir build && make build && make run
```
